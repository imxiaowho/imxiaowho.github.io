## Repository

This repository contains the published static site. The current snapshot is v0.24.42. Vercel serves the live site, and GitHub Pages redirects the original `imxiaowho.github.io` URLs to the corresponding paths on `imxiaowho.org`.

For a local static preview, run this command from the repository root.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Use the live site to check production redirects and share previews.

The included OFL notices cover the corresponding fonts.
