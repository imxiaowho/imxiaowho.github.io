撤销平台任务不会停止外部 Agent；已手动启动的执行请先结束。运行中或待核实的自动批次须先处理执行情况。

    
    

  

  

    
确认本批次并归档

    

    
确认后，本批待确认任务会进入“闭环记录”，关联采集原件从本线“待处置”移入“已处置”。

    
共享原件等最后一张关联卡闭环后归档；已归档原件须核验内容后登记。原回报、处理结论和执行历史继续保留。确认不会重新提交执行。

    

    

    

  

  

    
核实后转回手动

    

    
先打开原执行会话，确认原执行 Agent 未启动或已经停止。记录保留，系统不会自动重发已经尝试的报告。

    
    
    

  

  

    
删除异常卡片

    

    
这张异常卡片将移出执行列表，可以在“已删除异常卡片”中恢复。

    
原任务、采集原件和执行历史保留。删除或恢复卡片不会重新落库，也不会关闭任务。

    

  

  

    
撤回闭环 · 恢复进行中

    

    
只恢复所列卡片的处理状态。原件保留在归档目录；已有回报、闭环结论、知识库内容与沟通轮次保留。不会启动 Agent 或重新落库。
